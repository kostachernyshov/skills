# Glossary

| Word | Meaning |
|---|---|
| run | One iteration of the analysis. A folder `runs/RNN-<slug>/` with `run.yaml`. |
| status | State of a run: open, candidate, dropped, shipped. |
| release | A frozen set of results that the client saw. `releases/vN-<date>/`. Never changed. |
| brief | The one-page decision brief. |
| check | One test of plausibility with a status: pass, warn, fail. |
| prior | A published result that the analysis compares with. |
| frontier | The open questions in a grilling interview. |
| State | The section in `CLAUDE.md` that says where the work is now. |
