# Voice-over: how the skills work

<!-- English. About 2.5 words per second. One idea per scene. The scene ids match animation.yaml. -->

## S01
These skills take a bioinformatics project from a client's question to a decision you can trust.

## S02
A client asks you, the bioinformatician, two things at once: describe the immune cells in melanoma, and predict survival.

## S03
You type grill-me. The agent asks its questions first: who acts on the answer, why it can work, what is enough. Then you answer.

## S04
The request mixes two kinds of work, so grilling proposes two runs. First, a biological description, with the outcome locked away. Then, predict outcomes.

## S05
Before any data, a plan: what counts as success, and three controls. You approve it.

## S06
In a fresh session, the agent runs the plan and checks each result: T-cell genes in four hundred seventy tumors.

## S07
A fresh agent writes the report from the files. The supervisor checks it, and it passes.

## S08
The first run shapes the plan of the second. You approve it, and the outcome opens.

## S09
The agent runs the analysis and checks each result.

## S10
The report shows the result: patients with more killer T cells lived longer.

## S11
The supervisor answers seven yes-or-no questions. One no is a veto. The claim is fixed, and it passes.

## S12
If you want, the agent makes slides and a short video.

## S13
Last, the results go into a release. Only you sign it. After that, it does not change.

## S14
A big task can split into more runs, for example five. Each run has its own plan, analysis, report, and supervisor.

## S15
You can also run several tasks at once. Your part is to state each task well, answer the questions, and accept the result.

Type ask-kosta to start.
