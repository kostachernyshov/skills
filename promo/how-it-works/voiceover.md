# Voice-over: how the skills work

<!-- English. About 2.5 words per second. One idea per scene. The scene ids match animation.yaml. -->

## S01
These skills take a bioinformatics project from a client's question to a decision you can trust.

## S02
A client asks two things at once: describe the immune cells in melanoma, and predict survival.

## S03
First, the agent asks questions. Who acts on the answer? Why can it work? Each answer is marked: yours, or the agent's.

## S04
The request mixes two kinds of work. So grilling splits it. Run one describes the biology, with survival locked away. Run two works with the outcome.

## S05
Before any data, a plan: what counts as success, and three controls. You approve it.

## S06
In a fresh session, the agent runs the plan and checks each result. Run one: T-cell genes in four hundred seventy tumors.

## S07
Run one shapes the plan of run two. Now the lock opens. Patients with more killer T cells lived longer.

## S08
A fresh agent writes a one-page report. It reads only the files, not the chat.

## S09
A supervisor answers seven yes-or-no questions. One no is a veto. Here the claim was too strong. The report is fixed, and it passes.

## S10
Only you sign the release. After that, it does not change.

## S11
Then share it: a short deck for the meeting, or a video like this one.

## S12
A big task can split into more runs, for example five. Each run has its own plan, its own checks, and its own report.

## S13
You can also run several tasks at once. Your part is to state each task well, answer the questions, and accept the result.
